# 实时通话服务端装配离线候选

## 候选范围

本候选把已合并到工作分支的实时通话服务端模块接入生产组合根、生命周期、HTTP / WebSocket 入口与离线网络闭环。它不是完整 F2 验收，也不包含 Android 原生采集、播放、AEC 或界面实现。

通话能力默认关闭。只有 `call_transport.enabled=true`，且可信单 worker、非 reload 启动证据、默认角色实时语音供应商、CALL PCM TTS、通话概要、结算、Stage/Transport 绑定与启动恢复全部就绪时，`CallCapabilityStatus.available` 才为真。未知宿主、多 worker、reload、缺失依赖或非默认角色均拒绝 CALL，普通聊天保持可用。

## 生产装配与生命周期

- 正式启动链为 `server_main.run_server → ServerLifecycle → AdminShell → RuntimeSupervisor → ServerRuntime.initialize`。
- `ServerRuntime.initialize` 装配 SQL 呼叫账本、StageManager、CallStage transport、实时语音工厂、结算 consumer/coordinator、用户重置 fence、恢复服务与无内容指标。
- 业务就绪前等待 `StaleCallRecoveryService.reconcile()`；存在 failed 或 conflicted 恢复项时启动失败。
- `call.start` 支持首次创建与同 `client_request_id` 幂等身份；失败账本保持稳定 `call_id`，不会复活 Stage 或创建 Conversation。
- post-claim constructor、角色依赖查询、bind、provider/context start 失败统一关闭已拥有资源、发送一次 `CALL_SETUP_FAILED`、释放 ownership，并把账本置为 `FAILED`。
- pre-Stage registration、`preparing` 发送或取消失败通过 `StageManager.fail_pending_call_claim` 清除精确 pending claim、CALL lease 与 deadline，并持久化失败；已被 Stage 接管的 stale claim 无权释放当前 owner。
- 活动通话的 transport release observer 由 `CallTransportHub` 持有，并等待真实 `stage.wait_closed()`；Transport 不施加 20 秒活动期上限。Stage 终态后，terminal delivery 与 output drain 分别使用 2 秒清理预算，最后按 expected session 注销。
- Hub 与 Runtime shutdown 会关闭 session、取消并 gather owned release tasks；旧连接 generation 无法解除恢复后的新连接。

## 网络、重置与隐私证据

离线成功 E2E 通过生产 launcher 与 `ServerRuntime.initialize` 启动真实内部对象图，使用临时 SQLite、真实账号注册/登录/message token、chat switch、call WebSocket、AgentRuntime、StageManager、CallStage、ContextFactory、账本、settlement、adapter 与 transport。仅 LLM、vector store、实时语音供应商和 TTS 使用确定性外部 fake，不调用付费服务。

覆盖链路包括：

- `call.switch_prepare` 与相同 `client_request_id` 的 `call.start(seq=1)`；
- ACTIVE、合法 CALL/stream 0 PCM 上行及供应商收到相同 payload/内部 sequence；
- provisional/formal 音频、客户端实际播放完成回执、interrupt/stop；
- 三秒窗口内 resume、终态结算与历史概要隐藏；
- 鉴权数据重置后呼叫账本、Conversation、维护批次、记忆与画像清零，账号凭据仍可登录；
- SQLite 与真实子进程 stdout/stderr 日志不包含逐轮转录、完整概要、PCM/Base64 或完整上下文。

AC-18 指标生产者已接入状态、供应商、首包、正式回复、TTS、buffer、ACK retry、interrupt、stop、reconnect、概要、维护与 usage/cost unknown 等无内容数据；真实供应商计费准确性与生产观测后端未验证。
