## 范围

本域记录 CLI 端到端测试客户端（`client/` 侧、无 GUI）的对外契约：

1. **CLI 动作与机器输出契约**（S3 起填写）：动作名、JSONL 记录字段、稳定错误对象、进程退出码。
2. **无 GUI 会话门面**（S2 起填写）：连接/鉴权就绪/心跳/重连/事件订阅/ACK 等待/回复聚合（音频终止与落盘索引）；供 CLI 与 GUI 共同调用，不得出现第二套协议实现。
3. **后续切片**（S4 媒体与重放、S5/S6 图片与触摸、S7 动态、S8 偏好、S9 场景与报告）：各自 SPEC 阶段在本文增补。

### 2. 无 GUI 会话门面（目标，待 S2 填写）

草案（仅示意方向，S2 SPEC 阶段定稿后替换）：

- 建立会话：登录（HTTP）+ WebSocket 鉴权 + ready 三阶段完成后方可执行动作
- 连接维护：心跳、断线状态与重连语义（复用现有机制）
- 事件订阅：文本 / 音频 / 表情 / 终止包等事件流；按回复 UUID 聚合，`is_final_package` 才算完整
- ACK 等待：按 `reply_to` 关联客户端消息 ID；区分肯定 / 否定 / 重复 / 超时
- 音频索引：终止后落盘、可按回复 UUID 重放；临时反应（`is_ephemeral` / `display_in_chat=false`）不进索引
- 关闭：会话资源释放与不可恢复状态
