# 歌曲维护 CLI

入口：在 `server` 目录执行 `python scripts/music/add_segment.py --listen` / `--save`。输入仍为脚本顶部的歌曲、歌词、偏移配置及 `server/res/sing_song/luotianyi/songs/<歌曲目录>` 资源；路径从脚本位置解析，不依赖当前工作目录，也不新增公开参数。

- `--listen`：pydub 解码并按原时间截取，PyAudio 同步输出片段的采样率、声道及有符号整数 PCM，不生成预览临时 WAV。仅成功后打印播放完成。
- 缺少播放依赖时给出安装提示并退出；打开、写入失败向 CLI 传播，已创建的流和 PyAudio 实例在退出时释放。
- `--save` 的配置初始化、JSON 格式、歌词和时间语义保持不变；未要求试听时不加载播放依赖。
- 服务端依赖清单已包含 pydub、PyAudio；运行环境仍须提供相应解码器和声卡。该脚本不依赖客户端实现。

验证采用代码审查、编译检查和可重复的隔离 CLI 检查；隔离检查可在临时歌曲目录替换外部音频设备，确认选中 PCM 的格式、字节及资源释放，但不作为长期测试文件维护。真机验收使用真实 `ILOVEU.mp3` 完整验证 FFmpeg/pydub 解码和默认声卡输出；不专门测试已删除的导入。
