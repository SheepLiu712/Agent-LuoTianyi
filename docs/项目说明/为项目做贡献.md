# 如何为项目出一份力？
目前项目非常缺人！欢迎所有朋友为项目出一份力，只要你：
- 熟悉Python/Typescript/Unity编程，或者有其它一技之长；
- 认可本项目理念；
- 希望为项目做出贡献/锻炼自己的能力。

你就可以尝试为项目贡献代码！

## 关于AI工具使用
⚠警告：我们注意到中文Vocaloid社区对AI生成内容的极度敏感。在社区共识改变之前，我们**不会**向项目中引入：①AI生成的美术作品；②AI创作的音乐。因此，如果你想为项目贡献美术资源或者音乐资源，请确保这些资源不是由AI生成的。另外，你设计的功能不应引入 AI 生成美术作品或 AI 创作音乐的能力。但以下AI使用方式是可接受的：
- 使用LLM进行文本生成，例如对话回复、记忆管理、上下文压缩等；
- 使用开源的语音合成模型进行TTS合成，例如GPT-SoVITS。
- 使用AI辅助编程工具（如GitHub Copilot）进行代码编写，但核心逻辑和设计需要由开发者完成。
- 所有的判别式模型，例如人物识别、术语提取、情感分类等。所有不生成新内容的生成式模型（如伴奏分离）。
- 所有非神经网络的算法。

## 如何贡献代码
你可以用常用的方式贡献代码：
1. 将项目fork到你自己的目录；
2. 创建feat分支或bugfix分支；
3. 实现功能；
4. 提交Pull request，等待作者和协作者审核
5. 完成贡献！

在当下，AI辅助编程已经成为主流的编程方式。我们鼓励开发者使用AI辅助编程工具实现功能的具体细节，但提交者需要能解释、调试并维护由 AI 辅助生成的代码。

对开发者，我希望你能做到：
- 明确自己所需要开发的功能是什么，希望实现什么样的效果；
- 自己（或与AI共同）确定实现这一功能时的框架、逻辑，以及可能模块的编排；
- 检查功能与当前框架是否冲突，是否需要修改现有模块的接口或逻辑；
- 提供方法验证功能是否实现了预期的效果，是否满足验收标准；

## 还有其他贡献方式
我们也欢迎你为项目贡献以下内容：
- 美术资源：如果你愿意为项目提供美术资源，绘制角色的模型或服装，欢迎与我们联系；
- 文档：如果你发现文档中有不清楚的地方，或者有更好的表达方式，欢迎提交PR；
- 测试：如果你发现项目中有bug，或者有更好的测试用例，欢迎提交PR；
