## 本轮 UI 实现范围

- `app/components/call/CallScreen.tsx`：Android 通话页面的准备/呼叫/活动/重连/结束视觉状态，安全区、可访问标签、计时和主动挂断。
- `app/hooks/useCallSession.ts`：仅负责页面编排，复用冻结的 `CallSession.prepare/start/hangup/subscribe/onError/close` 接口；能力未由真实 resolver 注入时保持不可用，不构造假通话。
- `app/app/index.tsx`：菜单中的 Android 通话入口和不可用说明；入口只在服务端与 Native capability 均为真实可用时启动。
- `app/components/call/CallHistoryBubble.tsx`：历史记录的右对齐/时长/结果展示，无播放按钮、无摘要。

## UI candidate 交付说明

- 入口仅在 Android 且真实 server/native capability 注入后可用；当前 production resolver 尚未接入，默认保持 disabled，不构造假通话。
- `useCallSession` 支持一次性 `createSession` factory，并以 generation 绑定 snapshot subscription；退出时立即返回聊天，安全处理同步/异步 hangup、双 unsubscribe、close 和诊断回调异常，避免复用已关闭 session。
- ACTIVE/RECONNECTING 复用聊天页现有单一 Live2D WebView owner；CallScreen 只提供透明 controls/状态 overlay，不创建第二个模型。PREPARING/RINGING 的呼叫音仅通过可注入 `ringtone` port，生产播放器尚未接入。
- 历史 HTTP projection 通过 `mapHistoryMessage` 转换 `connected`、`cancelled_before_answer`、`declined` 与 `active_duration_ms`；组件不展示摘要或播放按钮。
- 本候选不关闭 Issue #282，不勾选验收 checkbox；Oracle UI 三轮历史结论仍为 `BLOCKED`，本记录不是第四次 review，也不是 human acceptance。

未在本轮实现或验证：真实 server 首次 `call.start` 组合、Native/Kotlin 编译与真机权限、设备音频/AEC/蓝牙、视觉运行时截图；未修改 transport/headless session、原 F1 录音器、server 或 shared types。
