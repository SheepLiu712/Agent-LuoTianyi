## Gate I remediation 1/3

- summary/maintenance 模型输入保留所有已完成用户轮次；只有 `COMPLETED` 且有 formal text 的角色回复会进入输入。NOT_STARTED/FAILED/INTERRUPTED 仍保留 user semantic，但不附加角色 partial text；provisional 从未进入 final snapshot。
- summary 在调用模型前按 stable Conversation UUID 查询已提交 winner；owner/character/call/outcome/duration/reason 必须与 ledger 一致。已有 winner 直接修复 summary CAS，不重调模型；并发 loser 在写冲突后回读 winner，不覆盖旧事实、不重复计数。
- AC-17 原文允许长期保存“成功提取的向量记忆和用户画像”，同时明确禁止“用户逐字转写、声音描述、情绪、Agent 逐轮回复和通话工作摘要”。据此新增 call-specific frozen batch，只保存最终长期 memory 候选的 type/content/index、完整 proposed profile、稳定 maintenance ID、身份范围与 status/timestamps；不保存 user semantic、formal reply、transcript、snapshot、模型输入、working summary 或 PCM。
- coordinator timeout 使用 shield + owned task 收束：15 秒不续期；取消后等待 consumer/context/to_thread 清理完成才释放 recall pool。该清理可能超过 15 秒，不能当作严格响应 SLA。新模型/新写入是否在 deadline 后启动由外层 task cancellation 和 Agent cancellation boundary 阻止；已进入 owned SQL/vector 操作会完成并按真实结果结算。
