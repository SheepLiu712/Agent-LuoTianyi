## 状态矩阵与清理策略

| CallScreen phase | 行为 |
|---|---|
| `SWITCH_PREPARING` / `CONNECTING` / `PREPARING` / `RINGING` | 启动一次 tagged activation |
| `ACTIVE` / `RECONNECTING` | 保持同一 tag；phase rerender 不重复 activation |
| `ENDING` / `ENDED` / `FAILED` / `DECLINED` | 释放本 owner tag；不影响其它 owner |
| 用户挂断/返回确认 | 既有 reducer 进入 `ENDING`，hook 随 phase 释放 |
| 后台 | 既有 `useCallSession` `app_backgrounded` 自动挂断政策不变，phase 收束后释放 |
| CallScreen 卸载 | cleanup 释放已持有 tag |
| activation 尚未 resolve 时卸载或转终止 | `mountedRef`/`desiredRef` 使 late continuation 补 `deactivateKeepAwake(tag)` |
| release reject | `console.warn` best-effort，不阻塞通话或其它 cleanup |

StrictMode/重复 render 下由 effect 依赖 phase、held/pending guard 和唯一 tag 防止重复占用；两个并存 owner 使用不同 tag，释放一个不会关闭另一个。
