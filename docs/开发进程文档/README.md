# 开发进程文档索引

本目录只在第一层展示当前仍参与开发决策的文档。已经完成、被实现取代或仅用于追溯历史决策的材料统一放入 [`归档`](归档/README.md)，归档不代表删除或否定当时结论。

| --- | --- | --- |

| [Agent 重构当前进度](开发进度/Agent-handle-realize-深模块重构.md) | 当前 Agent 重构完成事实、未验证范围与后续工作 | 每个相关行为切片完成时 |

| [Agent 架构与行为不变量](设计文档/Agent架构与行为不变量.md) | 需要长期保持的模块归属、请求隔离与副作用语义 | 生产架构或不变量变化时 |

当前源码 interface 的权威说明位于 [`docs/项目说明/项目架构与接口（spec）`](../项目说明/项目架构与接口（spec）/接口文档/README.md)。如果本目录中的历史进度与当前源码/interface 文档冲突，以当前源码、自动化门禁和 interface 文档为准。

代码风格、圈复杂度和覆盖率不维护结果快照：当前规则直接读取 [`server/pyproject.toml`](../../server/pyproject.toml)，测试命令见 [`server/tests/README.md`](../../server/tests/README.md)。需要结论时应在当前代码上重新执行检查。

## 整理规则

1. `开发进度` 只保留仍在更新的进度账本；完成的实施计划、交接单、PR 编排和一次性质量扫描移入归档。
2. `设计文档` 只保留跨迭代仍成立的架构与行为不变量；实现前提案、阶段 SPEC 和验收快照在完成后归档。
3. 产品版本计划和未来功能草案不作为当前 Server 架构依据；未进入当前迭代时放入归档，重新启动时应基于当时源码重新校准。
4. 归档文档保持可读、可追溯，但不再作为新增代码的默认依据。
