### 2026-09-21 登录存储接口

- SPEC 79e0abb；Red 39fb04e实际因五个登录存储能力缺失而失败；Green为本记录提交。StorageService增加profile原子读写和受保护令牌存取/删除，Godot实现复用CredentialStore，磁盘查询不变。
- test_login_storage与原test_storage_service通过：新安装、原子写回、加密令牌、账号/服务器隔离、损坏文件不覆写、不可写路径及不可用基类均验证。JSON数字按值检查，不将引擎解析的浮点数字误判为字段丢失。
- 作者自审：平台API仅在存储实现类，未新增明文降级或修改服务端；原热重载DLL差异未纳入。

### 2026-09-21 登录状态、历史与服务器验证

- SPEC 79e0abb；Red 0337139实际因账号历史/选项/手动令牌登录/服务器切换能力缺失而失败；Green为本记录提交。AccountSession唯一存储依赖改为StorageService，移出所有文件读写；调用者与现有测试显式迁移注入。
- 记住状态与启动自动登录分离，账号/服务器历史隔离，手动与自动令牌轮换、退出仅清当前凭据、取消记住/移除本地记录、旧单账号资料迁移均实现。服务器经既有公钥接口及本地原子保存成功才切换，失败/取消保留原地址。
- 账户组（含新login_profiles）、基础组及功能组均通过。新增测试覆盖普通HTTP失败保留令牌、本地保存失败不换服务器、缺失凭据回密码、只读文件迁移不覆写。独立只读核验与作者自审确认令牌删除失败会显式报告，历史仍可重试移除；不声称文件系统拒绝删除时已清除。无服务端变更。
- 当前引擎真实GPU已确认Window.transparent/transparent_bg及per_pixel_transparency/allowed可用，并导出默认normal、眼睛(1,1)的模型原始截图供静态头像制作；不将该截图当登录外框验收。

### 2026-09-21 白色登录场景与窗口切换

- SPEC 79e0abb；Red 8a23bc7实际因新场景入口/两项勾选/菜单/弹层及旧模式选择器未替换而失败；Green为本记录提交。所有固定控件为Godot场景，头像为已授权模型离线渲染的静态PNG，样式在统一主题，无渐变、矩形裁切或新增原生圆角代码。
- 默认480×690透明圆角小窗，顶部两键、固定三项菜单、服务器验证弹层、账号历史、注册/邀请码重置切页和敏感输入清理实现。记住状态诚实展示且可切回密码；日志跨登录保留，反馈通过独立平台能力，失败给可复制地址。登录后恢复系统窗框/展开几何，退出恢复固定登录形态。
- test_login_presentation使用完整本地HTTP/WebSocket fixture，覆盖菜单/服务器成功与Esc取消迟到响应、重置页草稿保留、记住状态重启及令牌轮换、返回清秘密、日志、浏览器失败、窗框切换、四档内容缩放与320×520小屏可达。账户组、场景/主题、相关功能组与GPU检查均PASS。
- 另外实际复现并修正：无账户服务时顶部退出/诊断入口不能失效；登录存储失败提示不能随登录页隐藏，现由主界面场景提示并在日志记录STORAGE_ERROR。图片存储/其他业务未改。
- 原生窗口探针仅操作自己启动的PID，确认顶栏拖动(36,24)、边缘不缩放、实际菜单截图、关闭结束进程；native-source.json为PASS。高倍测试显式清空固定设计视口尺寸，避免双重缩放。真实系统DPI与Win10仍未验证。
