# 移除 winsound 依赖

## Bug 与边界

客户端音频工具无条件导入 `winsound`，在其他依赖齐备的非 Windows 环境仍会导入失败。唯一使用它的 `play_audio()` 没有仓库内调用者；歌曲试听脚本和音频样例也保留了该后端。

- 删除客户端闲置函数、导入及标志，不改变现有音频接口。纯删除通过引用检查及现有回归验证，Red 不适用，不新增导入测试。
- 原音频样例保留文件读取、Base64 往返、播放和报错方式，只移除 Windows 分支，使用原有 PyAudio 分支；样例文件与 `client/tests/test_audio_base64.py` 同目录，不放在客户端根目录。
- 歌曲试听改为 PyAudio，保持片段范围、采样率、声道和整数 PCM 格式；释放已取得的设备资源。脚本基于自身位置读取当前歌曲库 `server/res/sing_song/luotianyi/songs`，不依赖启动目录。
- 不新增音频依赖、业务接口或跨项目导入；不修改 README 和开发指引。移除该限制不等于整个项目已通过跨平台验收。

歌曲维护 CLI 的可观察行为见[接口约定](../../../../项目说明/项目架构与接口（spec）/接口文档/system/music-tools.md)。
