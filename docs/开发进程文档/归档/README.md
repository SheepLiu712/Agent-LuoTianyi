# 开发进程文档归档

这里保存已经完成、被当前实现取代或暂不参与当前迭代的文档。内容保留用于追溯当时的需求、取舍、迁移顺序和验收证据，不应直接当作当前 interface 或待办清单。

## 分类

- [`Agent重构`](Agent重构/)：Agent 深模块重构的 PRD、总体 SPEC、分切片提案、实施计划、交接材料、旧验收记录和一次性质量债务快照。
- [`工程流程`](工程流程/)：已经退役或只适用于历史 PR 协作阶段的审查自动化、堆叠 PR 流程与门禁 Skill。
- [`产品版本规划`](产品版本规划/)：未处于当前开发迭代的版本 TODO、动态功能计划和电话功能设计。

## 使用约束

1. 查阅归档时先确认文档日期、代码基线和状态标记。
2. 恢复某项工作前，先用当前源码、配置和测试重新验证文档中的路径与假设。
3. 归档文档与当前文档冲突时，以 [`开发进程文档索引`](../README.md)列出的当前文档为准。
4. 不在归档文档中继续追加当前进度；需要恢复时先创建新的当前进度文档，并链接到历史材料。
