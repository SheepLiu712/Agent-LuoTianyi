## 1. 全局架构不变量

1. **认知与行动只有两个业务入口**：生产调用方按角色从 `AgentRuntime.get_agent()` 取得缓存门面，只调用 `handle_stimulus` 与 `realize_action_plan`；装配/关闭契约见 `server/src/agent_runtime/agent_runtime.py:111-229,463-513`、`docs/项目说明/项目架构与接口（spec）/接口文档/agent_runtime/README.md:6-17,49-64`。违反时可观察到 Stage/world/adapter 直接调用 conscious、skill 或旧业务代理，形成双轨。
2. **依赖方向**：Domain 只定义跨模块强类型数据，不访问 DB、网络、模型或文件（`docs/项目说明/项目架构与接口（spec）/接口文档/domain/README.md:3-6,51-55`）；Adapter 只做协议转换与交付；Stage 持有交互、pending、计时、取消和顺序；Agent handler/skill 决定认知与行动；World 负责外部事实、机械维护和时间唤醒。违反时会出现提示词/业务落库进入 Adapter/Stage，或 world 绕过 Agent 直接生成角色内容。

   - **落库**：Clock 自身无；`last_results` 为内存状态。
   - **LLM 调用**：Clock 自身无。

## 18. 失败与部分效果语义不变量

1. **链路名**：任一 handle/plan/action/输出/外部任务失败 → 从失败点停止 → 记录真实报告/日志 → 保留已提交效果 → 不重试、不降级、不引入 ledger/outbox/重投。
2. **触发/节奏**：同步/异步异常、取消、sink 拒绝、依赖不可用、输出回执失败或外部服务失败时立即生效；仅 WorldClock 继续下一周期，不代表重试同一次业务请求。
3. **旧架构实现**：`global_speaking_worker.py:124-158 @9ed8d1c` 与 `chat_stream.py:219-256 @9ed8d1c` 曾包含 terminal/response 重试；旧 topic/reflection 管线还可能用降级路径。#29 删除 RequestLedger/ExecutionLedger/PlanOutbox 和旧重试入口（进度账本 `:12-18`）。
4. **副作用清单**：
   - **爬取**：外部 HTTP 失败由各任务记 skipped/failed；不得生成成功事实。B 站吞异常返回零是已知冲突。
   - **落库**：已经 commit 的对话、记忆、事件、动态、评论不回滚；未拿到 EffectRef 不得写成功状态。
   - **LLM 调用**：失败不自动换模型/降级模板；触摸不降级聊天，世界事实不降级直写。
   - **发送信息**：OutputEmitter 首败停止；已发包/已完成 action 保留；取消补必要终包。
   - **调度**：不对单请求自动重试；Clock 的下一周期是新一次触发。关闭超时可由调用方再次调用 close/stop。
   - **去重·claim**：提醒失败 release claim；世界投递拒绝 discard settlement 登记；业务 source identity 防重复；无通用 ledger/outbox。
   - **文件读写**：已原子发布的媒体/报告/工件不因后续失败删除；staging 未发布不得冒充成功。
5. **必须保持的行为不变量**：单次执行按行动顺序，首败后不再调用后续 action/output sink；报告只列真实已提交 EffectRef；发布失败不伪造 dynamic/comment/diary；citywalk 动态失败不撤销 travel；学歌经验失败不撤销学会事实；回复执行取消不把已 consumed 输入重新加入；所有失败可从 report/log/状态列观察。
6. **验收方式**：**已有回归**：`test_output_delivery_failure.py`、`test_handler_dispatch.py`、`test_chat_reply_settlement.py`、`test_world_settlement_wiring.py`、citywalk/dynamic/diary/song 各 agent/world 失败用例、`test_world_clock.py`。**未验收**：跨进程崩溃、生产数据库中途断连、真实网络部分上传；设计明确不提供 outbox/重投，不能以灾难恢复标准误判当前实现。
