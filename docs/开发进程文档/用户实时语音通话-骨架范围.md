## 边界与未决决策

- `InteractionLeaseRegistry` 是进程内实现；分布式协调和多 worker 闸门仍待生产集成设计。
- `CallLifecycle` 只承载合法状态迁移，不能替代 CallStage 的时序、缓冲或 Agent 编排。
- `RealtimeSpeechSession` 不绑定供应商。SDK 或直连 WebSocket、降级行为由 Spike-A 与 ADR 决定。
- `CallSessionRecord` 只列出允许持久化的生命周期与结算事实；不包含音频、逐轮转录或工作摘要。SQL schema 和迁移尚未创建。
- `derive_call_conversation_id()` 要求调用方显式传入 UUID namespace；项目常量尚未选择。
- App 音频端口刻意不选择原生模块、codec 或 wire 布局。F1 的 AAC/M4A 文件录音不是实时流实现。

## 集成门槛

集成时逐项把骨架接到生产 Web、Adapter、Stage、Agent、持久化和 App 协调器，并以 spec AC-01…AC-19 的测试证据复核。骨架单测、fake 或 reducer 测试不代替 WebSocket、端到端、真机 AEC/路由及真实供应商验证。
