# agentluo · Windows 客户端

解压后双击 agentluo.exe。请保留同目录的 PCK、DLL、release.json 和 licenses。版本以 release.json 和窗口标题为准；无需安装 Godot、Python 或 .NET。此包是便携 Windows x64 客户端，不是安装程序。

登录前为紧凑账户窗口，默认沿用原客户端公共服务器；有效的自定义地址优先。支持注册、登录、邀请码重置、自动登录及退出。新端不导入旧端凭据，模型设置需重新填写。

登录后自动同步历史。首批完成前可以输入和发送，消息会显示“等待历史同步”；失败可重试或跳过本次同步。后台继续加载全部历史，不自动播放历史语音；已有本机阅读位置时尝试定位其后，用户操作后改为手动定位。历史图片按需恢复，可点击预览。输入区“＋ 图片”或Ctrl+V可添加单张图片，预览中显式发送，也可关闭预览后从输入区发送或移除；失败保留附件。支持PNG/JPEG/WebP/BMP，单张小于6MiB、每边最多8192像素且总像素不超过1600万。

Enter 发送、Shift+Enter 换行，正文可选择复制。左侧角色支持滚轮缩放、右键拖动、重置，中间分隔条可调整。主题色 #66CCFF；关闭即退出，无托盘模式。

在线语音默认播放，可调音量或停止。完整且保存成功的声音有重放、暂停、继续和停止按钮，显示真实波形及播放进度，不支持拖动进度。在线声音会中断本地重放；停止在线声音后仍接收并缓存完整流。错误流和临时回复不生成持久重放缓存。

语音缓存在 %APPDATA%/AgentLuo-Godot/audio，按服务器、账号和消息 UUID 隔离，退出及重启保留，无自动淘汰。设置中的“语音缓存”确认后清理，不删聊天文字。历史中只有新端本机已有的完整缓存可重放，不下载服务端未提供的旧语音，也不导入旧客户端或手机缓存。

左侧“设置 → 相处模式”可编辑关系、表达风格、性格关键词及补充上下文。加载成功才可保存；保存前重读并合并，不覆盖其他字段。设置和动态草稿在关闭、退出账号或程序时会询问是否放弃，默认取消。

“设置 → 语音缓存”用圆环显示本账号语音缓存占所在磁盘总容量的比例，并列出缓存大小、总容量和可用容量；未知数据显示“--%”，不会显示成零占用。可自行输入清理多少天之前的缓存，默认30天、0为全部；确认后执行并刷新统计，近期缓存和其他账号缓存保留。

“设置 → 模型配置”按服务端用途独立配置地址、密钥、模型、能力和高级 JSON 参数，可复制配置。模型配置保存到本机，不请求模型供应商；手动测试需确认可能消耗额度，仅发送固定短输入。启用后可执行服务端委托，支持 OpenAI 兼容的非流式接口。密钥默认使用 Windows DPAPI；保护失败时可明确选择明文保存，默认取消。不要把能力勾选或一次测试成功当作全面认证。

左侧“动态”打开独立任务栏窗口，聊天最小化后仍可使用。左侧动态列表、右侧完整详情，初次打开不自动选择；分隔条和窗口尺寸会保存。点击“回复”在该条评论下输入；取消回复对象保留文字，切换动态保留本次窗口草稿和阅读位置。发布动态使用当前动态窗口内的浮层，成功后选中新动态。列表和评论滚到底自动分页，失败可重试。新内容只更新未读提示，由用户刷新；浏览不会清未读，只有“全部已读”成功才更新。发送失败保留草稿；超时不自动重发，请先刷新核实，避免重复发布。

登录前后都可打开日志窗口。默认查看本次启动以来的完整记录，支持实时追加、搜索、模块/级别筛选、复制、暂停跟随和切换历史启动。日志持续保存于 %APPDATA%/AgentLuo-Godot/logs，正常关闭写结束标记，异常退出保留已写入记录；保留最近50次启动并保护仍在运行的实例。诊断 ZIP 导出所选启动的全部记录，不受筛选影响，不自动上传。日志不保存聊天/动态/评论正文、密码、token、密钥或音频原文；写盘失败会提示。

旧客户端仍可使用；用户数据目录保持不变。回退时运行保留的旧交付包，勿删除新端数据目录。新端不保存一套长期本地聊天正文数据库。

开发用离线样板：agentluo.exe -- --preview，模拟内容不连接服务器。公共服务器完整联调、真实唱歌听感、长期性能、Windows 10 和系统 DPI/集显真机验收仍需单独完成。此版本未切换项目正式下载入口，也未提供手机、换装或箱庭功能。

正式页面的下拉菜单采用统一白色圆角样式，支持方向键、Enter和Esc；长列表可滚动，窗口移动或最小化时收起。动态评论仅显示你与天依的私人互动，没有共享评论区或楼中楼。关闭动态窗口将一起检查发布及评论草稿，未提交草稿不保存到磁盘。


桌面应用窗口使用系统标题栏、最小化、最大化/还原和关闭按钮，支持系统拖动、双击与边缘缩放。应用内部与下拉圆角由Godot控件主题绘制，不使用遮罩。动态和日志在主窗最小化后仍可使用；设置随主窗隐藏和恢复。退出登录会关闭业务窗口，但日志保持打开；关闭主窗会退出整个应用。

左侧导航为聊天、动态、设置、日志。退出登录位于设置底部左侧；右侧为关闭和保存全部修改。相处模式与模型配置在同一设置窗口中切换，保存作用于全部修改。若部分保存失败，会说明未保存的项目并保留草稿。关闭有修改的设置时，可以保存并关闭、放弃或取消；只有全部成功才会保存并关闭。退出登录也会检查草稿，保存中请求退出会先等待保存结果。退出应用使用主窗系统关闭按钮，只汇总并询问是否放弃，不会自动保存设置或发送聊天/动态。

图片在全局共用的独立窗口中查看，可缩放、适应窗口或显示原始比例；换图时恢复适应窗口。图片窗归属当前图片的来源，随来源最小化与关闭。窗口大小、位置和最大化状态会记忆，显示器变化后会移回可见区域；未发送的文字不跨重启保存。
