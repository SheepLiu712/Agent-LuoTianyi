## 交付边界

客户端为独立 Windows x64 工程；现行改动不修改服务端、旧客户端或用户存储格式，不升级版本、不打包、不发布、不自动合并。触摸事件改用协议文档已规范的 `touch_area` 等 snake_case 字段名（服务端本就优先读取该名），属于对齐既有契约而非新增协议。公共服务、多屏、系统 DPI、Windows 10、集显、长期性能与移动端需另外验收。截图、历史 ZIP 和复杂度通过均不能代替相应行为验证。
