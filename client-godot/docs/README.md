## 交付边界

客户端为独立 Windows x64 工程；本轮修复不修改服务端、旧客户端、消息协议或用户存储格式，不升级版本、不打包、不发布、不自动合并。公共服务、多屏、系统 DPI、Windows 10、集显、长期性能与移动端需另外验收。截图、历史 ZIP 和复杂度通过均不能代替相应行为验证。
