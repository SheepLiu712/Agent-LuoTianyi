# AgentLuo Windows 客户端使用说明

## 0.2.0.3 当前源码

当前源码版本为 `0.2.0.3`。版本以 `release.json` 和窗口标题为准；本文说明的是当前源码的行为，重新打包后才能作为该版本的发布包。

客户端是便携式 Windows x64 程序，不需要安装 Godot、Python 或 .NET。解压发布包后，保留同目录的 `agentluo.exe`、`agentluo.pck`、`release.json`、`PREVIEW.md`、`licenses/` 和三个 DLL，双击 `agentluo.exe` 启动。版本以 `release.json` 和窗口标题为准。

## 登录

未登录时显示 480×690 的淡蓝色圆角窗口。窗口可以拖动，不能缩放，顶部只有菜单和关闭按钮。

“设置服务器”可以修改服务器地址。地址必须使用 HTTPS；只有 `localhost`、`127.0.0.0/8` 和 `[::1]` 允许明文 HTTP。保存前会先验证连接，验证成功后才应用。已经保存的自定义地址优先于内置默认地址。

“注册账号”使用未使用的邀请码。“忘记密码”使用已使用的邀请码重置账号，成功后用新账号登录。返回登录页会清除密码和邀请码输入。

账号框右侧的箭头列出当前服务器上保存过的本机账号。“记住登录状态”只保存受保护的登录令牌，不保存密码，下次启动仍需点击登录；“自动登录”会同时开启记住状态，并在启动时登录当前账号。退出登录会清除当前账号的令牌，但保留账号历史。移除本机账号记录不会删除服务器账号、聊天记录或缓存。

旧 Godot 单账号自动登录配置会自动迁移。旧 Python 客户端的凭据不会导入。

## 聊天

登录后窗口展开为 1280×800，最小 960×640。客户端先显示本地缓存，再在后台同步服务端历史。首批历史完成前可以输入和发送；消息会排队，不显示逐条等待状态。同步失败时可以重试或跳过本次同步。

聊天支持文字和图片：

- `Enter` 发送，`Shift+Enter` 换行。
- 文字可以选择和复制。
- 图片按钮或 `Ctrl+V` 可以添加一张图片。预览中确认后才发送；失败时保留附件。
- 支持 PNG、JPEG、WebP 和 BMP。单张小于 6 MiB（实际上限为 6 MiB 减 4 KiB），每边不超过 8192 像素，总像素不超过 1600 万。
- 图片按原比例显示，小图不放大，大图缩放到 250×250 以内。点击图片可以打开独立窗口查看原图。

消息气泡随文字宽度变化，最长到消息区的 90% 后换行并增高。相邻消息间隔至少 300 秒时显示时间分组。正常发送、排队和发送中不显示状态占位；发送失败或无法确认送达时保留异常提示，避免重复发送。

查看旧消息时发送新消息不会强制滚到底部，可以点击“回到最新”。输入框上方的分隔线可以上下拖动，高度范围 48–320 像素，松手后按账号保存。

左侧角色区域支持滚轮缩放、右键拖动和右下角悬浮按钮重置。中间分隔条可以调整角色与聊天区域的比例，比例会保存。

## 语音

服务端返回的 WAV/PCM 语音会自动播放。同一消息 UUID 的分片会合并；文本随分片到达立即更新，多条语音按顺序播放，后一句的语音在前一句播放结束后开始。正在播放的在线语音会中断本地重放。

输入框上方的音量图标可以展开滑条并调整音量，音量会保存。完整保存到本机的语音可以重放、暂停、继续和停止；波形来自原生解码器的 RMS 数据，播放进度来自混音器已消耗的帧。不能拖动进度。

语音缓存在 `%APPDATA%\AgentLuo-Godot\audio`，按服务器、账号和消息 UUID 隔离，退出和重启后保留。每个账号的缓存上限为 256 MiB，单条最多 16 MiB；超过上限时按修改时间从旧到新删除。缓存没有按时间自动过期，可以在“缓存与导入”页手动清理。历史语音只播放本机已有的完整缓存，不下载服务端未提供的旧语音。

## 动态

“动态”打开独立的任务栏窗口，聊天窗口最小化后仍可使用。窗口左侧是动态列表，右侧是完整正文和评论，默认比例为 35:65，分隔条和窗口尺寸会保存。

- 列表和评论滚动到底部时自动加载下一页。失败后可以继续滚动或点击刷新重试。
- 点击一条动态会加载它的完整评论，包括当前已经选中的那条。刷新期间保留评论草稿和阅读位置；未发送的评论与回复按账号保存，退出或重登后可继续编辑。
- 评论只在当前用户与角色之间可见，不是公共评论区；可以对单条评论回复，回复会显示在评论正文前。
- 发布动态使用窗口内的浮层。取消发布时会检查草稿；未发布的文字按账号保存，退出或重登后重新打开浮层即可继续编辑。
- 角色顶部的卡片只显示最新一条未读动态；只有评论未读时不显示。点开一条未读动态会在本机把该条标记为已读，圆点和徽标随之更新；这个操作不请求服务端。点击“全部已读”会先更新本机，再请求服务端；服务端失败时只提示错误，不回滚本机已读状态。
- 发送超时后不会自动重发。请先刷新确认，避免重复发布。

## 设置

设置窗口包含五个页面。关闭有修改的设置时，可以选择保存并关闭、放弃或取消；只有全部保存成功才会关闭。部分保存失败时会说明失败项并保留草稿。

### 个人资料

显示当前账号和本机头像。支持 PNG、JPG 和 WebP，单张不超过 6 MB。头像立即生效，只保存在本机，不参与“保存全部修改”。

### 相处模式

可以编辑关系、表达风格、性格关键词和补充上下文。页面加载成功后才可以保存；保存前会重新读取服务端配置并合并，避免覆盖其他字段。

### 模型配置

按服务端返回的用途分别配置服务商、Base URL、模型、能力和高级 JSON 参数。API Key 默认使用 Windows DPAPI 保护；保护失败时可以选择明文保存，默认取消。配置只保存在本机，不会上传到服务器。

“测试”会发送一次固定短输入，不发送聊天历史，可能消耗模型额度。测试成功只表示本次请求可用。启用后可以执行服务端委托，当前支持 OpenAI 兼容的非流式接口。

### 缓存与导入

用圆环显示整个客户端数据目录占所在磁盘的比例，并列出客户端已用、其他已用和剩余空间；圆环下方单独显示本账号语音缓存大小。没有上次扫描记录时显示“尚未扫描”，有快照时恢复上次扫描时间和结果；只有点击“开始扫描”或“重新扫描”才读取磁盘，未知数据显示“--%”。

可以清理指定天数之前的语音缓存，默认 30 天，填 0 表示全部。清理只影响当前服务器和账号的语音，保留聊天文字和历史图片。清理时会停止本地重放，在线声音继续播放。

也可以选择旧 Python 客户端的 `exe`，只读定位它的 `temp/tts_output` 和 `temp/images`，把消息 UUID 匹配的语音和图片复制到当前账号。源文件不改动，已有条目不覆盖；聊天文字仍从服务器读取。

### 风格外观

界面风格可选“扁平”或“清透”，图标风格可选 SVG 或 emoji。选择只修改草稿；点击“保存全部修改”后才应用。保存失败时保持原主题，并提示失败项。

## 日志

登录前后都可以打开日志窗口。默认显示本次启动以来的记录，支持实时追加、搜索、按类别、模块和级别筛选、复制、暂停跟随和切换历史启动。

日志分为业务流、网络通信、存储持久化和系统诊断四类，与 `DEBUG`、`INFO`、`WARN`、`ERROR` 四个级别相互独立。单次最多显示 1000 条匹配记录。

日志保存在 `%APPDATA%\AgentLuo-Godot\logs`。每次启动生成独立的 JSONL 和元数据文件，单次默认上限为 8 MiB 或 5 万条，保留最近 50 次启动，并保护仍在运行的实例。旧 schema v2 归档不再显示。正常关闭会写入结束标记；异常退出会保留已经写入的记录。

诊断 ZIP 导出所选启动的全部记录，不受当前筛选影响，不会自动上传。日志保留脱敏后的错误原文和堆栈，不写入聊天正文、动态正文、密码、令牌、`Authorization`、密钥或音频原文。写盘失败时日志窗口的状态文本会显示提示。`DEBUG` 级别默认关闭，可以用 `--debug-log` 开启。

## 窗口与退出

登录后主窗口和其他独立窗口使用系统标题栏、最小化、最大化/还原和关闭按钮。退出登录后恢复 480×690 的透明窗口和 Godot 绘制的淡蓝色圆角面板。

- 动态窗口和日志窗口在主窗口最小化后仍可使用。
- 设置窗口跟随主窗口隐藏和恢复。
- 退出登录会关闭动态等业务窗口，但日志窗口保持打开。
- 关闭主窗口会退出整个应用。

退出应用或退出登录前会先保存聊天与动态草稿。已保存的草稿不会阻止退出；只有未保存的设置修改、正在发送的请求或草稿写盘失败会列入退出确认，并明确提示退出后将丢失。设置保存过程中请求退出时，会先等待保存结果。

窗口大小、位置和最大化状态会保存；显示器变化后，窗口会移回可见区域。未发送的聊天文字、待发送图片、动态发布、评论与回复会按账号保存在本机，退出应用或退出登录后，下次登录仍可继续编辑。

## 离线预览

不连接服务器时，可以用预览模式查看界面：

```powershell
agentluo.exe -- --preview
```

预览窗口默认 1200×800，最小 960×640。角色区支持滚轮缩放、右键拖动和右下角按钮重置；左上角可以切换七种表情；右上角可以切换“日常聊天”“空白会话”“网络断开”“加载失败”“正在思考”五种状态。

聊天区可以输入并模拟发送，`Enter` 发送，`Shift+Enter` 换行。图片按钮或 `Ctrl+V` 会先打开预览，确认后才追加演示消息。模拟口型按钮只改变角色口型，没有声音。预览不连接账户、消息、语音或模型服务。

预览模式也支持截图：

```powershell
agentluo.exe -- --preview --scenario=empty --capture=<截图路径>.png
```

`--scenario` 可选 `conversation`、`empty`、`disconnected`、`error`、`thinking`。截取登录页时不加 `--preview`：

```powershell
agentluo.exe -- --capture=<截图路径>.png
```

截图和 headless 检查不会自动登录真实账号。

## 已知限制

- 当前只支持 Windows x64，不提供 Android、iOS 或网页版本。
- 换装、虚拟世界和设备互联只有预留接口，界面没有入口。
- 公共服务器联调、真实语音服务、系统 DPI 切换、多显示器、Windows 10、集成显卡和长时间运行需要单独验证。
- 本地回归和 GPU 截图不能代替上述实机验证。
