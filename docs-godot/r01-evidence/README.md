# R01 练习验证记录

2026-10-02，源码基准 `2ea9870`。对应 [R01 初学者教材](../R01-入口与应用装配详解.md)。

## 环境与方法

- Godot `4.7.1.stable.official.a13da4feb`，Windows 图形模式，使用实际主场景 `scenes/main.tscn`。
- 将运行所需项目文件复制到临时目录；每组单独设置 APPDATA/LOCALAPPDATA，不读真实登录资料，不进行登录操作。
- 冷导入先出现主题纹理导入时序错误；随后运行副本的 `scripts/check.ps1 -ImportOnly`，引擎版本/哈希及导入检查通过。没有把首次进程退出码 0 当作无错误。
- 验证脚本实例化真实主场景，等待初始化和绘制，读取 Window.size、Username.placeholder_text、Submit.disabled、布局状态、空会话和用户目录，再截图；它不另绘一套界面。
- 练习改动仅存在于副本，验证后恢复。原项目 99 个 `src` GDScript 文件前后 SHA-256 相同。
